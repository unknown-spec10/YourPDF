YourPDF Desktop — install
=========================

Requirements: Windows 10 or 11, 64-bit. No admin rights are needed.

One-click install
-----------------
1. Open https://github.com/unknown-spec10/YourPDF/releases/latest
2. Download YourPDF-Desktop-setup.exe
3. Double-click it. It installs for your user and launches. No wizard, no admin prompt.

Direct link:
  https://github.com/unknown-spec10/YourPDF/releases/latest/download/YourPDF-Desktop-setup.exe

One command (online)
--------------------
Open PowerShell (Start menu, type "PowerShell") and run:

  powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/unknown-spec10/YourPDF/releases/latest/download/install.ps1 | iex"

It downloads the latest release, verifies its SHA-256, installs YourPDF
Desktop for the current user, and launches the app.

Offline
-------
Keep these three files in one folder, then run install.cmd (or run install.ps1
from PowerShell):

  YourPDF-Desktop-setup.exe
  SHA256SUMS.txt
  install.ps1

Updates
-------
Run the same command again. The installer replaces the previous version and
keeps your settings.

Uninstall
---------
Settings > Apps > Installed apps > YourPDF Desktop > Uninstall.
App data (%LOCALAPPDATA%\com.yourpdf.desktop) is left in place; delete that
folder yourself for a completely clean slate.

Unsigned build
--------------
The v1 installer is not code-signed, so Windows SmartScreen may show
"Windows protected your PC". Choose "More info" > "Run anyway". The SHA-256
check above is what guarantees the downloaded file is the one published.

Privacy
-------
Everything runs on this machine. Files are never uploaded. Tools only talk to
127.0.0.1. The single outbound request is the optional update check, which
fetches latest.json from GitHub — no files and no telemetry are sent.
