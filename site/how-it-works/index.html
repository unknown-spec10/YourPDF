Privacy framework & technology

YourPDF Desktop is designed from the ground up to respect your privacy and data security — by never taking your files off your own machine.

1. On-device processing

Every tool — from merging and splitting to OCR and text extraction — runs inside the app on your own CPU. There is no upload step: you pick a file from disk, the local engine processes it, and the result is written straight back to disk.

2. Ephemeral working files

Heavy tasks (compression, rasterization, OCR) write scratch files to a private temp folder owned by the app. That folder is cleared immediately after each task finishes, so intermediate copies never accumulate on your disk.

Local processing engine

The installer ships a self-contained processing engine that the desktop app starts on demand and keeps bound to your machine only. Each job is handled synchronously — the file is read, transformed, and written out — with no network round-trip in between:

Direct file results
Output is written directly to the location you choose — no queue, no polling, no expiring download link to come back to.
No outbound traffic
The app never uploads documents. Working copies exist only in the app's private temp directory, for the duration of a single task.
Auto-cleanup
Temporary files are hard-deleted the moment the task finishes — not on a timer, and with no background cleaner left running.

Because everything runs locally in short-lived tasks that clean up after themselves, large files are processed quickly without sacrificing privacy. All of the code is open-source, so you can audit it or build it yourself from the repository.
